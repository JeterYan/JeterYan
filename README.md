### 🚀 Pilares do meu Portfólio Back-end

Meu portfólio é estruturado de forma independente para demonstrar domínio em diferentes cenários da engenharia de software corporativa:

*   🟢 **Pilar 1: Core Business & Transacional ([processamento-pagamento](https://github.com/JeterYan/processamento-pagamento))**
    *   API REST focada em regras de negócio complexas, consistência de dados, tratamento global de exceções e simulação de transações financeiras.
*   🟡 **Pilar 2: Alta Performance & Processamento em Lote (Em Breve)**
    *   Motor de conciliação de dados utilizando **Spring Batch** para manipulação eficiente de arquivos massivos e grandes volumes de dados sem gargalos de memória.
*   🟡 **Pilar 3: Arquitetura Orientada a Eventos & Microsserviços (Em Breve)**
    *   Worker assíncrono (consumidor puro) integrado a brokers de mensageria (**RabbitMQ/Kafka**) focado em processamento desacoplado em segundo plano.
